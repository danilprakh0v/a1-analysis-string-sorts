# A1. Анализ строковых сортировок

В данном репозитории представлено практическое исследование стандартных и специализированных алгоритмов сортировки строк. Проводится сравнение их производительности (времени выполнения и количества посимвольных сравнений) на различных наборах сгенерированных данных.

## Структура репозитория

В репозитории находятся все файлы, необходимые для проверки работы и воспроизведения результатов:

* `A1 StringSort Analysis - RL, DP.cpp` — исходный код на C++, содержащий генератор тестовых данных, реализации всех тестируемых алгоритмов сортировки и класс-тестер для автоматического сбора статистики.
* `A1 StringSort Analysis, DP.ipynb` — Jupyter Notebook (на базе Python, Pandas и Seaborn) для агрегации данных и построения графиков.

## Исследуемые алгоритмы

В рамках исследования были реализованы и протестированы следующие алгоритмы сортировки (в прямом лексикографическом порядке):
1. Standard Quick Sort (Стандартная быстрая сортировка)
2. Standard Merge Sort (Стандартная сортировка слиянием)
3. String Merge Sort (С использованием длины наибольшего общего префикса — LCP)
4. String Quick Sort (Тернарная быстрая сортировка для строк)
5. MSD Radix Sort (Поразрядная сортировка без переключения)
6. MSD Radix + String Quick Sort (Гибридная сортировка с переключением при малых размерах подмассива)

## Краткие выводы

Проведенное исследование подтверждает, что стандартные алгоритмы сортировки совершают избыточное количество операций при обработке строк с длинными совпадающими префиксами. Специализированные алгоритмы, адаптированные для работы со строками (в частности, гибридный MSD Radix + String Quick Sort), радикально снижают число посимвольных сравнений и показывают наилучшее время выполнения.
